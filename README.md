> 碎碎念
> 
> 写了四年逆向，现在觉得自己有点多余

四年前我偶然接触到逆向，从此一发不可收拾。

其实这股执念埋得很早。以前看影视剧，总觉得屏幕前敲几行代码就能摆平一切的黑客特别帅，心里一直很向往。高考填志愿时，我毫不犹豫地选了计算机专业。进了大学真正开始写代码后，我不满足于课本上的那点东西，总喜欢自己琢磨着造点小工具。顺着这条路一路往下摸索，我第一次接触到了逆向，开始试着去拆解 App 的底层逻辑。

那种感觉跟单纯写业务代码完全不同，更像是在和开发者隔空对弈。我在猜对方当初是如何设计的，这种博弈很有意思。从最初的抓包分析、动态调试，到后来一点点啃下复杂的协议结构与加密校验，过程虽然枯燥，但每一次打通链路带来的正反馈都是实打实的。大学四年，我把大把的课余时间都砸在了这上面，也顺理成章地写了一些小有影响力的项目。在那个阶段，技术壁垒清晰可见——每一行代码、每一个还原出来的结构，都得靠时间、试错和经验去死磕。

AI 刚介入开发流程时，我其实是很乐观的。

有一段时间，我重度依赖 Claude 4 来辅助编码。它帮我分担了大量重复性的架构搭建和逻辑补全，我的开源仓库也正是在那个阶段迅速完善起来的。那时候人与 AI 的边界很清晰：我是主导者，负责拆解核心问题、把控方向；AI 是高效的执行者，帮我把想法快速落地。

但这种平衡并没有维持太久。

随着模型一次又一次迭代，当新一代旗舰模型 Claude 5.5 已经能惊艳地生成视频，当 Astra 开始直接制作游戏和 3D 建模，当网络上越来越多的人开始搞起“单机复活”，我先是感到兴奋，觉得未来一片大好，紧接着却涌上一股前所未有的无力感。模型的推理能力和上下文理解跨过某个临界点后，我突然发现，自己过去四年积累的很多经验正在被直接“平推”。以前需要靠直觉和经验去排查的细节，现在模型几秒钟就能给出最优解。坐在电脑前时，我甚至会生出一种荒诞的念头：我在这里敲键盘似乎是多余的，我那点有限的精力和手写代码的速度，反而在拖慢 AI 的发挥。

这种落差在维护项目时显得尤为刺眼。

受限于现实精力，我已经很难像以前那样高强度地跟进新版本的适配与更新了。但更让我失落的是，就算我不更新，似乎也无所谓了。如今的开发门槛已经被降到了地板上，任何人只要打开对话框，像“许愿”一样描述清楚需求，就能在短时间内复刻出我那个仓库八成以上的功能。我花了几个月甚至几年才走通的路，别人用几个 Prompt 就直接绕过去了。

比个人努力贬值更让人疲惫的，是随之而来的社区生态恶化。

当技术不再有门槛，开源精神在很多人眼里就成了可以随意收割的红利。现在随处可见这样的乱象：有人把开源框架拉下来，自己连核心代码都没看懂几行，直接丢给 AI 魔改一番、套层壳，转头就敢拿出去打包圈钱。真正花时间研究原理、填坑维护的人在幕后默默消耗，而靠 AI 缝合、吸开源血的人却在台前理直气壮地收割流量与利益。

写下这些，并不是想否定 AI 的价值，技术进步本身无可厚非。只是站在个人的角度，看着自己过去四年的积累在短短一两年内迅速失去意义，心里难免空落落的。仔细想想，编码或许更适合纯粹作为一种兴趣，而不是拿来谋生的工作。

放在以前，写代码、搞技术是实打实的饭碗，但现在大环境肉眼可见地变了。AI 的效率太高，高到很多常规岗位根本不再需要那么多人力，身边裁员、失业的消息越来越常见，大批刚毕业的学生拿着简历却找不到工作。市场变得极其现实，代码本身不再重要了，人们只盯着最终交付的结果，根本没人在乎背后的实现过程。

当“搞懂底层原理”不再是解决问题的必要条件，经验壁垒也被算力轻易抹平，习惯了在底层世界里慢慢打磨的人，在这个时代究竟还剩下多少不可替代的价值？

也许时间会给出答案吧。
